## Project Overview

Fake Job Detector (FJD) — an ML-powered system to classify job postings as real or fraudulent. Uses a TF-IDF + Logistic Regression pipeline (scikit-learn) trained on the Kaggle "fake_job_postings.csv" dataset. The project is structured for a full-stack deployment: ML model, FastAPI backend, and browser extension frontend.

## Commands

```bash
# Setup
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# Train model (run from project root, outputs model/job_classifier.pkl)
python model/train.py

# Evaluate model on test set
python model/evaluate.py
```

## Architecture

- **`model/`** — ML pipeline. `train.py` builds a TF-IDF (15k features, bigrams) → LogisticRegression pipeline, saves to `model/job_classifier.pkl`. `evaluate.py` loads the saved model and reports accuracy, precision/recall/F1 for the fake class, and example predictions.
- **`backend/`** — FastAPI API server (not yet implemented). Dependencies (fastapi, uvicorn, python-multipart) are already in requirements.txt.
- **`extension/`** — Browser extension frontend (not yet implemented).
- **`tests/`** — Test directory (not yet implemented).
- **`data/`** — Dataset directory (gitignored). Requires `data/fake_job_postings.csv` from Kaggle.

## Key Details

- Both `train.py` and `evaluate.py` must be run from the **project root** (they reference `data/` and `model/` as relative paths).
- The dataset (`data/fake_job_postings.csv`) and trained model (`model/job_classifier.pkl`) are gitignored. The model can be regenerated by running `train.py`.
- The model uses `random_state=42` and `stratify=y` for reproducible train/test splits. `evaluate.py` relies on this to reconstruct the same test set.
- Target column is `fraudulent` (0=real, 1=fake). The dataset is imbalanced (~4.8% fake), so `class_weight="balanced"` is used in the classifier.
- Python 3.14 venv is used (see `venv/`).
